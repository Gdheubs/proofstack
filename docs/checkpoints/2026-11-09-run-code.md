# Code editor: Run and Preview — November 9, 2026

Parent: `a9c89cf`. Delivers the owner-approved plan (step 2 of the Code roadmap): run code in the browser at no running cost.

## What members get

- A **Run** button in the editor's title bar (**Preview** for HTML files) and **Ctrl/⌘ + Enter** in the editor. A bottom panel with **Output**, **Input** and **Preview** tabs, a status line with the run time, **Stop**, and **Clear output**.
- **Python** (Pyodide 0.29.5): `print`/`input()` with the Input tab (typed input is echoed), imports between the repository's `.py` files (all of them in small projects; the program's folder in large ones, at most 60 files and 2 MiB), standard library, and bundled packages such as NumPy loaded on import. Tracebacks start at the member's own file. The engine stays warm between runs.
- **JavaScript and TypeScript**: `console` output with readable objects, errors with file, line and column, timers and intervals; TypeScript types are removed with sucrase (loaded only when needed), not checked. Imports between repository files are refused with a plain message for now.
- **HTML preview**: the page with its linked CSS, JS, JSON and SVG files from the repository, live as you edit (700 ms after typing stops); images load from the repository's public raw address (public GitHub repositories); links to other pages are disabled inside the preview.
- A one-time note: code runs on your own device, in a sealed sandbox with no access to your ProofStack account.
- Limits: 10 seconds per run (Python's first download is not counted, up to 90 s), 1 MB of output, Stop at any time.

## How it stays safe

- Code runs in `public/runner/run/` and pages in `public/runner/preview/`, served with `Content-Security-Policy: sandbox …` without `allow-same-origin` (`public/_headers`). Both get an opaque origin: no cookies, no storage, no access to the editor page. The session cookie is `SameSite=Lax`, so even a request from these pages to ProofStack carries no session.
- The runner may connect only to `https://cdn.jsdelivr.net` (the Python engine); programs cannot reach any other address. Every Pyodide core file is fetched with a pinned SHA-384 integrity check before Python starts; packages are checked by Pyodide against the integrity-checked lock file.
- Programs run in a classic Web Worker (module workers cannot start in an opaque origin); each JavaScript run gets a fresh worker, so one program cannot affect the next. Messages from the frames are accepted only from our own frame and shown as plain text.
- Nothing runs on ProofStack servers; no API or database change.

## Known limits

- No Java, C/C++, Go or Rust (needs the server-side runner, next roadmap step); no terminal, `npm install`, Node servers, or network calls from Python; JavaScript runs as one file; programs work on a temporary copy and never write to the repository.
- The opaque-origin sandbox has its own browser cache partition, so Python may download again after the editor page is reloaded (it stays loaded while the page is open).
