## Current decisions

### Staging Beta Readiness — **Not yet approved**

The application builds and regression tests pass locally, and its configuration
now targets Vercel, Render and Supabase. A limited staging beta with
**non-sensitive synthetic data** is still blocked until a fresh Supabase
project, authenticated smoke run, hosted CI result, and private storage
authorization test are recorded. Uploads, native Git hosting and workers must
remain disabled while their gates are open.

### Production Readiness — **Not approved**

Production evidence is absent for durable storage, real authentication events,
privacy deletion, recovery, monitoring, capacity and provider failure modes.
Passing source tests or builds does not close those gates.

## Free-tier boundary

Render Free cannot provide a durable disk or always-on worker. Supabase Free
does not provide automatic backups and can pause inactive projects. Vercel
Hobby is restricted to personal/noncommercial use. Production therefore
requires a paid/durable API and worker runtime, managed backups with tested
restore, a monitoring/alerting service, and a Vercel plan appropriate to the
commercial deployment.
